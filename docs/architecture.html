Jarvis Voice Visualization architecture note

Audio is the clock.

Jarvis is a browser visualization library with a small Bun session service. The browser talks to the service once for a short-lived secret, then speaks directly with OpenAI over WebRTC. Remote agent audio drives both the canvas and the paced transcript.

ArchitectureMap boundaries

The API key stops at the BFF.

The public packages own browser behavior. The server is a Backend for Frontend (BFF): a small backend written for this browser client, not a general-purpose API. It owns the long-lived OpenAI API key and turns it into an ephemeral client secret. After that handoff, the browser exchanges SDP, microphone audio, remote audio, and realtime events directly with OpenAI. Microsoft documents the Backends for Frontends pattern in more detail.

Solid cyan lines stay inside the application. The amber dashed link is provider and network work. Its timing varies by network, browser permissions, ICE negotiation, model processing, voice generation, and playout. The page does not claim an end-to-end latency.

PUBLIC LIBRARY

Core owns behavior

packages/core/src/voice-viz.ts mounts the canvas, routes normalized realtime events, owns the state machine, attaches remote audio, and runs the per-frame loop.

PRIVATE SERVICE

The BFF owns the secret

server/src/routes/session.ts checks request method and origin, applies in-memory limits, parses preferences, and asks OpenAI for a client secret.

Module ownership

Each module owns one piece of the path.

packages/core/src/transport/openai.ts

Fetches the secret, obtains microphone media, negotiates a peer connection, sends SDP to OpenAI, normalizes provider events, and tears down tracks and channels.

packages/core/src/state/state-machine.ts

Maps realtime events to idle, listening, thinking, speaking, interrupted, and error.

packages/core/src/audio/media-stream-analyser.ts

Connects the remote stream to Web Audio. Its analyser produces byte frequency and waveform buffers for the feature extractor.

packages/core/src/audio/speech-features.ts

Turns the raw buffers into VoiceFeatures. The values are level, onset, silence duration, spectral centroid, voiced confidence, frequency bytes, and waveform bytes.

packages/core/src/render/canvas-renderer.ts

Owns requestAnimationFrame, resize handling, a capped device pixel ratio, a capped frame delta, canvas clearing, visual clipping, and ordered preset painting.

packages/core/src/render/registry.ts

Maps preset names to painters. The five shipped layers are bars, waveform, ring, particles, and hud.

packages/core/src/text/audio-text-sync.ts

Queues audio-synchronized provider transcript chunks and releases stable words or CJK graphemes only as audible time earns character credit.

packages/core/src/text/streaming-panel.ts

Builds and paints the on-canvas Pretext text panel. The panel preserves timed chunks so text motion can react to arrival time and audio features.

packages/core/src/transcript/store.ts

Keeps an in-memory snapshot of user and agent messages. Consumer adapters read this store for an accessible transcript outside the canvas.

server/src/providers/openai-session.ts

Builds the provider session policy. It selects the model, semantic VAD behavior, response reasoning effort, output voice, speech speed, and Chinese input transcription.

ConversationSequence timing

A conversation crosses the BFF once, then stays peer to peer.

The session request is an HTTP boundary. The live conversation is a WebRTC boundary. Orange regions show variable time that belongs to the network, provider, or browser. Fixed values below are local constants in the repository. For the overloaded word "session", the mint secret, and when the live call ends, read What is a session.

The 20 second timer limits local connection setup. It is not a performance promise. The provider round trips and remote playout above are variable by design.

01 · request
The browser posts preferences.
packages/core/src/transport/openai.ts sends responseTiming and speechRate to the configured endpoint.
Network timing is variable.
02 · mint
The BFF validates and mints.
server/src/routes/session.ts allows only configured origins, checks rate and session budgets, then calls the provider endpoint with the protected key.
Network and provider timing are variable.
03 · connect
The browser negotiates media.
The transport captures microphone audio, opens oai-events, posts the SDP offer with the ephemeral secret, and accepts the SDP answer.
20,000 ms local connection timeout.
04 · listen
Provider events set state.
Speech start becomes listening. Speech stop becomes thinking. User transcription enters the transcript store when available.
Provider turn detection and transcription timing are variable.
05 · answer
Remote audio starts the visual path.
The incoming track creates an audio element and a MediaStreamAnalyser. Audio transcript deltas queue until detected speech earns text credit.
Provider generation and playout timing are variable.
06 · finish
Silence closes the text queue.
After an audio-synchronized response ends, the synchronizer holds for silence before it flushes remaining text and the state returns to idle.
850 ms local silence tail hold.

State machine

State follows events, not audio level.

packages/core/src/state/state-machine.ts keeps the semantic session state small. The renderer receives that state with the audio features, but no canvas preset decides session state from a visual threshold.

idle→ connect or connected →idle→ user-speech-started →listening→ user-speech-stopped →thinking→ agent-audio-started →speaking→ response-done →idle

Interruption

If a user starts speaking while the state is speaking, the machine enters interrupted. packages/core/src/voice-viz.ts interrupts queued text and marks the agent transcript message interrupted.

Failure and disconnect

A normalized error enters error. A disconnect resets the machine to idle, detaches local browser media resources, and clears active audio text synchronization.

UI command path

UI commands ride the same Realtime channel.

The BFF declares perform_ui_actions when it mints the session. After WebRTC starts, the BFF does not receive or execute tool calls. OpenAI sends a finalized function call to the browser. Core normalizes it. VoiceViz re-emits it. The demo parses it, runs an XState actor, and returns one structured result on the same data channel.

Amber dashed arrows are provider events on the existing WebRTC data channel. Cyan arrows stay inside the application. Pointer and keyboard requests share the actor and skip the result port.

ready→ dequeue →validating→ parse →executing→ capabilities →reporting→ one result →ready

Two machines, two jobs

Input transcription fills the transcript store. Model function selection emits perform_ui_actions. The voice-session machine still uses idle, listening, thinking, speaking, interrupted, and error. The demo actor uses ready, validating, executing, and reporting. A response.done event returns the session machine to idle. It is not the UI command result.

Bounds and exactly-once reporting

The FIFO queue holds eight requests. Completed call IDs keep the last 64. Duplicate call IDs are ignored. Execution is ordered, one command at a time, with a 2,000 ms wait for a target to register. Cancellation stops remaining work and lists already applied effects. The actor submits one result per accepted voice call. A cancelled result sets continueResponse to false so no unsolicited spoken follow-up starts.

FramePipeline requestAnimationFrame

Every frame samples sound before it paints a layer.

The renderer does not receive raw provider events. Each animation frame receives a compact VizFrame with state, state age, VoiceFeatures, regions, theme, reduced-motion status, and a capped delta time.

Measure the mount

CanvasRenderer uses ResizeObserver. The canvas uses a device pixel ratio capped at 2 to avoid runaway backing-store size.

Choose the source

VoiceViz samples the remote MediaStreamAnalyser, a supplied feature source, or the idle source in that order.

Extract VoiceFeatures

The analyser uses FFT size 2048 and smoothing 0.78. The extractor computes smoothed level, onset, silence milliseconds, centroid, voiced confidence, and preserves the byte buffers for painters.

Lay out regions

computeRegions places the panel at the side only when auto placement sees width at least 640 and a wide enough host. Otherwise it puts the panel at the bottom.

Paint in layer order

The registry creates named presets. The renderer sorts them by layer, clips them to the visualization region, paints them, and then paints the text panel.

Frame safety. CanvasRenderer caps its delta at 100 ms. That prevents a long tab pause from producing one huge particle update or animation jump.

Audio-paced transcript

Text waits for audible speech.

Provider transcript deltas and remote playout do not share a timestamp. AudioTextSynchronizer therefore treats detected remote speech as the local clock. It gives text a small initial credit, then adds credit in proportion to audible time.

PACE

18 characters per second

The base pace is 18 chars/s. The application can multiply that pace through setTranscriptPace.

TAIL

850 ms silence hold

Once source text is done and audio falls silent, the queue waits 850 ms before it flushes any remainder.

FALLBACK

5 second startup timeout

If text completes but audible audio never starts, the queue flushes after 5,000 ms.

Stable chunks

English-like text releases complete whitespace-terminated words. CJK text releases graphemes as they arrive. The panel batches CJK layout at four graphemes to avoid relayout for every character.

Credit cap

Each tick adds only a delta capped at 250 ms. Credit also has a bounded ceiling. A stalled animation frame cannot make the transcript jump far ahead.

The text panel is visual. packages/react/src/transcript-view.tsx offers the accessible React transcript view from the same store.

Demo transport

Simulation uses the same events with fixed delays.

apps/demo/src/demo-transport.ts implements the same transport shape as the live client for the visualization lab. apps/demo/src/voice/voice-demo-transport.ts does the same for the voice-first app, including tool-call parity. Neither models network or provider latency.

Lab turn schedule

The first synthetic user turn begins after 180 ms. Synthetic speech lasts 650 ms. The agent starts streaming after a further 460 ms. Word chunks arrive every 135 ms, and the next turn starts after 1,600 ms.

Synthetic signal

DemoVoiceFeatureSource writes deterministic-shaped frequency and waveform arrays. It reports a low idle signal. During agent speech, it varies level, onset, centroid, and waveform phase so the same canvas path remains active.

Voice-first scripts

Each UI script emits speech boundaries, user text, and one normalized tool-call with a unique call ID. Ordinary Q&A emits an assistant response with no tool call and leaves UI state unchanged.

Result acknowledgement

submitToolResult records the matching call ID. Successful and failed results stream a short agent transcript. A cancelled result with continueResponse set to false does not start that follow-up.

Operational notes

A few boundaries are easy to miss.

The BFF has no application authentication

Origin checks and in-memory budgets constrain the demo service. They do not identify users. Production deployments need application authentication and durable, shared limits if multiple instances run.

The BFF keeps no conversation data

The server retains only in-memory origin rate-limit and session-budget counters. The transcript store lives in the browser process for the mounted visualization.

Remote audio is deliberately attached

VoiceViz creates a muted autoplay audio element for the remote stream and also connects the analyser to the audio context destination. The analyser has a monitor option for direct use.

Check the environment variable name

server/src/config.ts reads PORT and defaults to 3010. server/.env.example still lists SERVER_PORT. That variable is ignored by the current config.

Provider policy is server-owned

openai-session.ts sets output voice echo and input transcription language zh. The browser sends response timing and speech rate, but it never receives the standard API key. The same request also declares perform_ui_actions. Tool calls still travel browser to OpenAI, not through the BFF.

Custom elements isolate their own CSS

VoiceVizElement mounts inside an open Shadow DOM root. The internal canvas and styles do not inherit a host page's global canvas styling.

The data channel must be open

submitToolResult throws when the Realtime data channel is missing or not open. The interaction actor treats that as a reporting failure rather than dropping the result silently.

Disconnect can beat the result

If the session disconnects before the actor sends the function output, remaining actions stop and the app records that reporting could not complete. Reconnect starts a fresh session. Do not switch simulation and live sources while voice work is pending.
